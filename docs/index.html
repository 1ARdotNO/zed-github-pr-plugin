zed-github-pr

Manage GitHub pull requests from inside Zed.

Repository · Design · Roadmap

What it is

A Zed extension that ships an MCP context server for GitHub PRs: list and filter pending PRs, inspect one in detail, switch between GitHub accounts, get desktop notifications on updates, and open a review — from Zed's Agent Panel, a terminal CLI, or an interactive dashboard.

Zed extensions can't draw custom panels, so the PR logic lives in a small native binary (ghpr-mcp) that Zed launches as a context server. The same binary is also a CLI and a TUI, so nothing forces you through an AI.

Install

gh auth login                       # authenticate (add more accounts anytime)
cargo install --path crates/ghpr-mcp # build + install the ghpr-mcp binary
# Zed → Extensions → Install Dev Extension → this repo's root folder

In Zed (Agent Panel)

Ask the agent, e.g. "list open PRs that need my review". It calls:

ToolWhat it does
list_pull_requestsList/filter PRs (repo, state, author, assignee, label, search, view, account).
pr_detailOne PR's body, reviews, checks, and changed files.
list_accountsThe GitHub accounts gh is signed into.
review_prAssemble a review prompt (title + body + diff) from your template.
notification_settingsShow the effective notification config.

Named views (view): needs-my-review, mine, assigned-to-me, involves-me. Accounts: pass account to scope a request to one of your gh logins, without changing the active one.

Terminal (CLI) & dashboard

ghpr-mcp prs --view needs-my-review   # filtered PR list
ghpr-mcp pr 42                        # one PR in detail (JSON)
ghpr-mcp review 42                    # print a review prompt
ghpr-mcp tui                          # interactive dashboard (repo from cwd)
ghpr-mcp watch --repo owner/name      # poll + desktop-notify on changes

The dashboard shows open PRs with color-coded checks (5/7), approval, age, and diff stats. Keys: j/k move, g/G top/bottom, Enter open in browser, r refresh, ? help, q quit. Run it inside Zed's terminal via the shipped .zed/tasks.json "GitHub PRs" task and a keybinding.

Notifications

ghpr-mcp watch polls open PRs and fires native desktop notifications (macOS osascript, Linux notify-send) when one is approved & ready, gets a comment, a new commit, or a checks change. Configure it at $GHPR_CONFIG or ~/.config/ghpr-mcp/config.json: 

{
  "poll_interval_secs": 120,
  "comment_cooldown_secs": 300,
  "suppress_self": true,
  "exclude_bots": true,
  "silenced_users": ["some-bot"],
  "desktop_notifications": true,
  "events": { "approved_ready": true, "new_comment": true }
}

Noise controls: never notify on your own actions, exclude bot/GitHub-App comments, silence specific users, and debounce comment bursts.
